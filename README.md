## Tech Stack
- **Framework:** Laravel 11
- **Templating:** Blade
- **Styling:** Custom CSS
- **JS:** Vanilla JavaScript

---

## Run Locally

```bash
git clone https://github.com/YOUR_USERNAME/keerthana-portfolio.git
cd keerthana-portfolio
composer install
cp .env.example .env
php artisan key:generate
php artisan serve
```

Open **http://localhost:8000**

---

## Update Content

> Edit only **`config/portfolio.php`** to update skills, projects, experience, or contact links. No need to touch any other file.
